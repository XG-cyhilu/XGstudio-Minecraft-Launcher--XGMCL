## 功能

- 多游戏目录版本管理
- 原版 / Fabric 安装（支持镜像源）
- Mod 管理（列表、虚拟滚动、拖拽导入）
- 一键升级版本（批量迁移 Mod 到新 MC 版本）
- Modrinth 集成（搜索、详情页、下载）
- LittleSkin 账户支持（设备代码 OAuth）
- 离线账户
- Java 自动检测
- 版本独立配置
- 内置日志查看器（游戏 / 启动器 / 自定义日志）
- 内置 webview 浏览 Modrinth
- 主题自定义 + 毛玻璃 / 液态玻璃视觉效果
- 直接开服（Fabric 服务端管理）
