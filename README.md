## Features

- Version management across multiple game directories
- Vanilla / Fabric installation with mirror support
- Mod management (list, virtual scrolling, drag-and-drop import)
- One-click version upgrade (batch mod migration to a new MC version)
- Modrinth integration (search, detail page, download)
- LittleSkin account support (device-code OAuth)
- Offline accounts
- Java auto-detection
- Per-version isolated configs
- Built-in log viewer (game / launcher / custom log)
- Built-in webview for Modrinth browsing
- Theme customization + glass / liquid visual modes
- Direct server hosting (Fabric server management)
