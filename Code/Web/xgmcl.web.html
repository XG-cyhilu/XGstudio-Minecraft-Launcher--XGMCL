FEATURES

为 Minecraft 玩家而生

现代化架构、流畅体验与开源精神，一切为了更好的游戏启动体验。

NT 架构 · 极速启动

后端从 Python 全面迁移至 Node.js，初始化时间从约 16 秒缩短至约 8 秒，整体启动速度快 2 倍。

现代 Mod Loader 支持

内置 Fabric / Quilt / NeoForge 三大现代 Mod Loader，自动下载并合并版本 JSON，开箱即用。

多源并发下载

BMCLAPI 镜像与官方源自动切换，支持断点续传、SHA1 校验与多线程并发，下载稳定可靠。

多种账户登录

支持离线账户与 LittleSkin 设备代码流登录，内置皮肤裁剪与 3D 皮肤预览。

Mod 一站式管理

内置 Modrinth 搜索、安装、启用/禁用、批量删除，支持前置依赖树分析与一键升级。

集成服务端与终端

一键安装 Fabric 服务端、可视化管理配置与插件，并内置多会话终端，开发调试两不误。

主题与界面自定义

主题色方案、毛玻璃/液态玻璃、动态壁纸、标题栏风格均可自由调整，打造属于你的启动器。

多语言与日志系统

支持中、英、德、法、日等多语言（含彩蛋），完整的启动器与游戏日志查看、压缩与归档。

NT ARCHITECTURE

全新 NT 架构

将原本基于 Python + JS 的 XGstudioMinecraftLauncher，转变为更快、更稳定的 NT 架构。

  • 后端由 Python 迁移至 Node.js，文件数从 7 个扩展到 32 个

安装说明

三步即可开始游戏。

1 · 下载并解压

下载 Windows 版压缩包，解压到任意目录（建议路径不含中文和空格）。

2 · 运行启动器

双击 XGMCL.exe 启动。首次运行可能触发 Windows SmartScreen，选择「仍要运行」。

3 · 登录并下载游戏

添加离线或 LittleSkin 账户，选择版本后点击下载，完成后即可启动游戏。

FAQ

常见问题

遇到问题？先看看这里有没有答案。

为什么我的游戏无法启动？
你可能没有安装 Java 运行时，或版本过低/过高；也可能是没有添加账户。详情可以加入官方群询问。
为什么启动器无法启动？
请检查你的环境是否已经达到了最低要求。
找不到 Java 怎么办？
请确认你已经安装了 JRE 或 JDK。如果为绿色版，请点击全局设置页的「深度扫描 Java」。
启动器的日志 / 配置保存在哪？
同目录的 XGMCL 文件夹保存配置和日志（XGMCL/xgmcllog/）；同目录的 .xgstudiomclauncher 文件夹保存你默认下载的版本及 mod 等。
下载过慢怎么办？
请查看启动器日志，如果没有错误，请切换下载源。
支持什么 Mod 加载器？
支持现代的 Mod Loader：Fabric、NeoForge、Quilt。请注意，我们并不支持 Forge。
如何反馈 Bug？
加入官方群 903815517，或在 GitHub Issues 提交。必要时请附上启动器日志。

关于 XGMCL

一个开源、现代化的 Minecraft 启动器，由个人开发者 XG 打造。

项目简介

XGstudio Minecraft Launcher（简称 XGMCL）是一款基于 Electron + Node.js 构建的开源 Minecraft 启动器。项目采用全新 NT 架构，专注于提升启动速度、稳定性与用户体验。

当前状态

Beta 公开测试版 —— 启动器仍在积极开发中，功能可能变动，可能存在 bug。欢迎通过 GitHub Issues 或官方 QQ 群反馈问题。
